# Product Manager Portfolio

Hi, I'm Yuliya, a Product Manager in training at the STRV Product Academy.
This repo follows **one feature from idea to delivery**: "Anywhere" for Booking.com, a search that starts with *when* and *who* and helps travellers discover *where*.

> All work here is a learning exercise. Booking.com is used as an example product; data, interviews and system details are assumptions made for the exercise.

## The case: Booking.com "Anywhere"

**Problem → MVP → Prototype → Requirements → Roadmap → Tickets**

| # | Stage | What I did | Skills shown |
|---|---|---|---|
| 01 | [**Feature proposal**](01-feature-proposal-booking-anywhere/) | Found an underserved segment (travellers who know *when* but not *where*), defined personas, MVP scope with explicit cuts, a North Star metric, and re-scoped under a 50% budget cut | Discovery, prioritisation, metrics, trade-offs |
| 02 | [**Design, prototype & requirements**](02-design-prototype-booking-anywhere/) | Moodboards and brief, an AI-built clickable prototype of 3 flows, and a short functional requirements doc engineering can build from | Design thinking, AI prototyping, spec writing |
| 03 | [**Delivery in action**](03-delivery-in-action-booking-anywhere/) | Roadmap with T-shirt estimates, an AI skill that turns the spec into tickets, working with developers | Planning, AI workflows, collaboration *(in progress)* |
